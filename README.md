# 新規LP制作スターターmd

## 最初に送るファイル

壁打ち開始時は、以下をCodeXへ送ってください。

1. `00_PROJECT_BRIEF.md`
2. `01_REFERENCE_NOTES.md`
3. `02_WORK_RULES.md`
4. `03_DECISIONS_LOG.md`
5. 参考サイトURL
6. 壁打ち用プロンプト

## 使い分け

- `00_PROJECT_BRIEF.md`
  - 今回のLPの基本情報・目的・ターゲットを管理
- `01_REFERENCE_NOTES.md`
  - 参考サイトの分析と取り入れたい考え方を管理
- `02_WORK_RULES.md`
  - CodeXが守る実装・報告ルール
- `03_DECISIONS_LOG.md`
  - 決定事項、変更理由、制作履歴を記録

## 企画確定後に追加するファイル

- `DESIGN_RULES.md`
- `IMAGE_ASSETS.md`
- `HANDOFF.md`

これらは商材・ターゲット・コンバージョン・世界観が決まってから作成してください。

## 最初の進め方

1. 参考サイトと4つのmdを送る
2. 商材案を壁打ちする
3. 3案程度を比較する
4. 商材・ターゲット・コンバージョンを決める
5. PROJECT_BRIEFとDECISIONS_LOGを更新する
6. DESIGN_RULESを作る
7. IMAGE_ASSETSを作る
8. セクション構成を確定する
9. HTML / CSS / JavaScript実装へ進む
