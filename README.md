# つむぎ行政書士事務所 LP

個人事業主向けの契約書相談サービスを題材にした、ポートフォリオ掲載用の1ページLPです。契約書に不安がある方が、専門家へ相談するまでの心理的なハードルを下げることを目的に、企画・デザイン・実装を行いました。

> **本サイトはポートフォリオ制作を目的とした架空のWebサイトです。実在する行政書士事務所・人物・地域・住所・サービスとは関係ありません。**

## プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | つむぎ行政書士事務所 LP |
| 制作区分 | 自主制作／架空サイト |
| サイト形式 | 1ページLP |
| 想定サービス | 個人事業主のための契約書相談 |
| 目的 | 契約書相談への不安をやわらげ、相談予約へつなげる |
| コンバージョン | 30分無料相談の予約 |
| 実装 | HTML / CSS / JavaScript |
| GitHub | [Coconattsu0723/tsumugi-lp](https://github.com/Coconattsu0723/tsumugi-lp) |

## コンセプト

**ブランドメッセージ**

> 仕事と安心を、契約でつむぐ。

**メインコピー**

> 分からないまま使う契約書を、安心できる契約書へ。

契約書の内容や雛形の使い方に不安を持つ個人事業主が、「まず相談してみよう」と思えるLPを目指しました。すでに契約書を持っている方だけでなく、まだ契約書を用意していない方も相談できることを、ページ前半から明確に伝えています。

## ターゲット

- 個人事業主・フリーランス・小規模事業者
- 契約書の内容を理解したまま使えているか不安な方
- インターネット上の雛形をそのまま使用してよいか分からない方
- 契約条件を整理したいが、まだ契約書を用意していない方

## デザイン方針

- 人物・相談風景・事務所の写真を主役にし、人柄と相談時の雰囲気を伝える
- アイコンは情報理解を助ける補助要素として使用する
- ライトブルー、ディープネイビー、ソフトコーラルを中心に構成する
- 士業らしい信頼感と、相談しやすい親しみやすさを両立する
- コーラルはCTAや重要なアクセントに用途を絞る
- 375pxを基準としたモバイルファーストで設計する
- 日本語に `Noto Sans JP`、英数字に `Inter` を使用する

フレームワークやビルドツールは使用せず、HTML / CSS / Vanilla JavaScriptで実装しています。

## レスポンシブ設計

SPを基本とし、画面を単純に拡大するのではなく、幅に応じて列数・情報配置・視線の流れを段階的に変更しています。

| 画面幅 | 主な設計 |
|---|---|
| 375px / 390px | 1列中心のSPレイアウト。HeaderはMENU表示、FLOWは縦タイムライン |
| 768px | タブレット向けの中間レイアウト。写真と文章、一部一覧を2列化 |
| 1024px | PC Header・Hero・FLOWへ切り替え。FLOWは左右交互配置 |
| 1200px前後以上 | 職種一覧を3＋2、契約書例を3＋3へ展開 |
| 1366px / 1440px | 最大幅1200pxでコンテンツを制御し、ワイド画面での間延びを抑制 |

表示確認は **375px / 390px / 768px / 1024px / 1366px / 1440px** の6幅で実施しています。

## 主な実装内容

- SP / PCで切り替わるHeaderとナビゲーション
- SP MENUの開閉、リンク選択後の自動クローズ、Escapeキー操作
- 写真とコピーの優先順位を調整したレスポンシブHero
- 画面幅に応じたカード・一覧の列数変更
- 相談手順を示すFLOW
  - SP / Tablet：縦タイムライン
  - PC：中央線を基準にした左右交互配置
- HTMLの `details` / `summary` を使用したFAQ
- ページ内リンクによる相談フォームへのCTA導線
- HTML標準の入力チェックAPIとJavaScriptを使用した無料相談フォーム
- ダミー送信後の完了メッセージとフォーカス移動
- 正式ロゴを利用したfavicon

無料相談フォームはポートフォリオ作品のデモです。入力内容の保存や、外部サービス・サーバー・メールアドレスへの送信は行いません。
